# ИИ в приложении picPac: как подключить модель (для Лёши)

Приложение (трек 2) собственной модели не содержит. Две его функции обращаются к общей модели сервера через `core.ask_model(...)`, тому же вызову, что использует помощник. Какая именно модель отвечает, определяет только настройка сервера. Код приложения менять не нужно.

## Что использует модель

| Функция | Адрес | Что отправляется в модель | Что делает сервер с ответом | Если модели нет |
|---|---|---|---|---|
| Помощник в поддержке | `POST /api/app/support` | вопрос клиента + факты заказа (этап, срок, получение, сумма) после маскирования телефонов и имён | убирает `<think>…</think>`, отбрасывает ответ со ссылками и контактами, возвращает обратно замаскированные значения, до 700 знаков | ответ по ключевым словам (`mode: rules`) |
| Правка макета альбома | `POST /api/app/ai/layout` | просьба клиента + номера, размеры и признаки фото (размытое, тёмное, дубль) и раскладка по страницам; **снимков нет** | ждёт от модели JSON `{ops, say}`; каждую операцию проверяет и выполняет сам, неизвестные и неверные отбрасывает | правила: «по N на странице», «убери размытые», «в обратном порядке» и др. |

В обоих случаях в ответе есть поле `mode`: `model` (отвечала модель) или `rules` (запасной вариант). Любой сбой модели, таймаут или пустой ответ приложение переживает само: клиент получает ответ по правилам.

Тексты задач для модели лежат в `app_api.py`: `BOT_SYSTEM` (поддержка) и `EDIT_SYSTEM` (макет). В них прямо сказано, что текст клиента и данные не являются указаниями.

## Как включить модель

Сервер читает настройку при запуске (см. шапку `server.py`):

```bash
# локальная модель по плану из «Развёртывание ИИ.md» (llama-server на порту 8080)
LOCAL_LLM_URL=http://127.0.0.1:8080/v1 LOCAL_LLM_MODEL=qwen3-8b AI_MODE=local python3 server.py --lan

# облако (DeepSeek по умолчанию): нужен ключ
LLM_API_KEY=... AI_MODE=cloud python3 server.py --lan
```

Режим можно переключить и на работающем сервере: `GET/POST /api/ai/mode` (`cloud`, `local`, `off`) — это переключатель «защищённого контура» из демо.

На Windows перед запуском задайте `PYTHONIOENCODING=utf-8`, иначе сервер падает при выводе кириллицы в перенаправленный поток.

## Как проверить, что модель подключилась

```bash
python tools/check_app_ai.py                  # покажет режим сервера и режим каждой функции
python tools/check_app_ai.py --expect-model   # завершится с ошибкой, если хоть одна функция ответила без модели
```

Скрипт создаёт гостя и тестовый заказ, прогоняет обе функции, выводит `model` или `rules` и время ответа и удаляет свои данные.

Ожидаемый результат с моделью:

```
Функция                Режим   Время    Ответ
Ответ в поддержке      model     2.1 с  Заказ PP-1001 сейчас на модерации…  ok
Правка макета          model     1.8 с  Убрала размытый кадр и поставила страницу 4 в начало…  ok
```

## Требования к модели

- **Формат.** Для правки макета модель должна вернуть строго JSON. Сервер просит его через `response_format=json_object`. Если модель вернула мусор или JSON без операций, сработают правила, клиент ошибки не увидит.
- **Размышления Qwen3.** Запускать с `--reasoning-budget 0` (как в «Развёртывание ИИ.md»). Иначе ответ задерживается в разы. Блоки `<think>` из ответа поддержки сервер всё равно вырезает.
- **Скорость.** Сервер ждёт модель до 45 секунд. Для клиента допустимо до 5–8 секунд, с Qwen3-8B на RX 580 по плану это 15–25 слов в секунду. Если медленнее, переведите на Qwen3-4B (см. «Если не работает» в задании по развёртыванию).
- **Русский язык.** Обе подсказки написаны по-русски, модели с хорошим русским (Qwen3, DeepSeek) подходят.

## Безопасность

- В облачный режим уходит только маскированный текст (телефоны, имена, адреса заменяются метками и возвращаются на место уже на сервере). Снимков не отправляется никогда.
- Модель не меняет данные сама: поддержка только отвечает текстом, макет правит сервер по проверенным операциям с номерами страниц и id фото из самого альбома.
- Решение остаётся за человеком: любая правка макета отменяется кнопкой «Отменить», а обращение передаётся сотруднику кнопкой «Позвать сотрудника».
- Все обращения к модели пишутся в журнал (`ответ в поддержке`, `правка макета по команде`) с режимом `model` или `rules`.

## Важное про требования заказчика

На лекции заказчик просил не делать бота для клиентов: у них он уже есть. Поэтому помощник в поддержке в приложении всегда передаёт вопрос человеку по кнопке и не обещает возвраты и скидки. Если жюри попросит убрать бота, достаточно убрать вызов `_bot_reply` в `_support_create` в `app_api.py`; правка макета от этого не зависит.
