# UX приложения picPac: что и почему

Принцип: меньше решений до первой пользы, понятный язык вместо терминов, всегда видно, что дальше и сколько стоит.

## Что изменено (11.11.2026)
| Было | Стало | Зачем |
|---|---|---|
| Экран входа перед каталогом | Сразу гость, «Войти» в шапке и в «Профиле» | Вход до первой пользы отпугивает; учётная запись нужна позже |
| Сначала выбор продукта | Главная кнопка «Выбрать фото», ниже поводы («Выпускной альбом», «Свадьба», «Календарь 2027») и продукты | Люди приходят с поводом и фото, а не с названием продукта |
| Плоские значки в каталоге | Живые картинки продуктов (книга, фото, календарь, магнит, холст) из тестовых кадров, заглушки-скелетоны при загрузке | Каталог выглядит как витрина, а не как список |
| «Проверка» с перечнем замечаний | Кнопка «Исправить автоматически» (убрать слабые кадры, включить белые поля), замечания по важности | Человек не должен сам разбираться с размытостью и обрезкой |
| Ошибки формы одним текстом внизу | Ошибка под полем, фокус на первое неверное, ошибка исчезает при исправлении, промокод спрятан за «У меня есть промокод» | Меньше полей на виду, понятно, что исправить |
| «Шаг» без номера | «Шаг 2 из 4» под заголовком | Видно, сколько осталось |
| Лента статуса с подписью | Лента из 5 пунктов + фраза «Проверяем макет, обычно около часа» + блок «Что дальше» | Тревога «что с заказом» снимается словами, а не только цветом |
| Прежний черновик терялся при выборе другого продукта | Фото возвращаются в «Мои фото» | Работа не пропадает |
| Мелкие кнопки | Не меньше 44 px (кнопки 48–56), шрифт 16 px, видимая рамка фокуса, Esc закрывает окна, уменьшенное движение учитывается | Доступность, крупный текст по просьбе заказчика |
| Резкая смена экранов | Мягкий переход 0,2 с | Ощущение «живого» приложения |
| Свой язык оформления | Светлое «жидкое стекло» в цветах picPac из пульта (`shared/glass.css`): тёплый фон с пастельными пятнами, стеклянные карточки, красный градиент на главной кнопке (темнее, чем в пульте, чтобы белый текст читался) | Приложение и пульт выглядят как одна система |
| Нет разговора с другими покупателями | Вкладка «Идеи»: шаблоны от компании (выбрал — черновик создан, остаётся добавить фото) и отзывы по своим заказам с ответами компании | Идея из лекции заказчика: показать, что делают другие, и дать готовый старт |

## Что изменено 12.11.2026 — одно оформление с пультом
| Было | Стало | Зачем |
|---|---|---|
| Три файла стилей поверх своей палитры (`shared/ui.css`), красный на вкладках, выбранных вариантах и кнопках | Один файл `t2/app.css` на переменных пульта (`shared/glass.css`): выбранное и вторые кнопки — тёмно-зелёные, коралловая только главная кнопка экрана | Приложение и пульт — одна система; красный не спорит со статусом «плохо» |
| Плоская нижняя панель | «Плавающая» стеклянная панель с перетекающим указателем, как боковая панель пульта | Узнаваемый общий приём |
| Статус — пять мелких кружков в ряд, подписи 11 px | Вертикальная лента: этап, пояснение, время | Крупный текст по просьбе заказчика |
| Сообщение о статусе — только на экране заказа | Уведомление на любом экране и список уведомлений | Имитация push из ТЗ |
| Отказ по файлу — строка на 4,5 с | Причины по каждому файлу остаются на экране | Человек успевает прочитать |
| На главной только поводы | Блок «Для вас» по фото, заказам и сезону | Персональные рекомендации из ТЗ 6.5 |
| На ноутбуке справа — «что мешает заказать» | Журнал «Что уходит в пульт» и переходы в пульт, на экран участка, в аналитику | На показе видно, что это одна система |

## Источники
- Printbox, рекомендации по магазинам персонализированной печати (сначала загрузка фото, вход через поводы, крупные цели касания): <https://getprintbox.com/blog/online-store-design-tips-for-beginners/>
- Printbox о мобильной конверсии: <https://www.getprintbox.com/blog/mobile-conversion-personalized-print/>
- Popsa о создании фотокниги на телефоне (меньше шагов до оплаты): <https://popsa.com/perspectives/how-to-make-photo-book-on-phone/>
- Baymard Institute, исследования мобильного оформления заказа: <https://baymard.com/research-articles/mobile-checkout>
- Сайт заказчика super.picpac.by: две главные кнопки («Выбрать фотокнигу», «Напечатать фото»), сценарии в карточках («Свадьба, юбилей…»), цены «от …», обещание бесплатной перепечатки при браке.
- Бесплатные страницы Baymard и Printbox показали общие принципы; полные руководства Baymard платные, поэтому конкретные числа (размеры целей касания и т. п.) взяты из общепринятых норм (44–48 px), а не из этих источников.

## Что ещё можно улучшить (не сделано)
- Белорусский язык рядом с русским.
- Умная раскладка по разворотам с учётом лиц и горизонтов.
- Проверка на настоящих людях: 5 человек проходят путь без подсказок, замеряем время и места, где остановились.
