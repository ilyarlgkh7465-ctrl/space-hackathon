## Трек 2 · приложение picPac
| Что | Лицензия | Где |
|---|---|---|
| Python, стандартная библиотека | PSF | сервер, тесты |
| Браузерные API (Canvas, IndexedDB, Service Worker, fetch) | веб-стандарты | `t2/app.js`, `t2/sw.js` |
| Шрифты Onest и JetBrains Mono | SIL OFL 1.1 | `shared/fonts/` |
| Значки | нарисованы нами (SVG в коде) | `t2/app.js` |

Сторонних библиотек, моделей и наборов данных в приложении нет. Анализ фото (резкость, яркость, дубли по dHash, умная обрезка) — свои алгоритмы, работают на телефоне. Тестовая галерея рисуется в браузере.
Все данные в приложении выдуманные.
