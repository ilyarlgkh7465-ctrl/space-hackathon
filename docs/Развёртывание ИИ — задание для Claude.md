# Задание для Claude: развернуть локальный ИИ на демо-ПК

Ты — Claude Code на демо-ПК команды хакатона «Фотопринт». У тебя есть доступ к этому компьютеру. Задача: скачать, установить, настроить и проверить всё, что нужно для работы системы **без интернета**: языковую модель, распознавание и синтез речи, наш сервер. В конце — автозапуск и отчёт.

Подробности для людей — в `docs/Развёртывание ИИ.md` из того же репозитория. Этот файл — твой план работы.

## Железо (проверь, что так и есть)

- **Одна** AMD Radeon RX 580, 8 ГБ; **16 ГБ** оперативной памяти (4 × 4 ГБ, 1600 МГц — платформа, скорее всего, старая); SSD 256 ГБ. (Уточнено 11.11 вечером: раньше план был на две карты и 32 ГБ.)
- **ROCm эти карты не поддерживает** (Polaris, gfx803). Не ставь ROCm, не пытайся запустить PyTorch/faster-whisper/Ollama на видеокарте — не выйдет. Рабочий путь — **Vulkan**: llama.cpp и whisper.cpp в сборке Vulkan.
- Распределение на одной карте: **и языковая модель, и распознавание речи — на Vulkan0**, синтез голоса — процессор. 8 ГБ видеопамяти — впритык, поэтому иди по вариантам:
  - **Вариант А (пробуй первым):** Qwen3-8B Q4 с контекстом 4096 + Whisper large-v3-turbo на той же карте. Оставляй, если после запуска обоих и по одному тестовому запросу занято **не больше 7,3 ГБ** видеопамяти и скорость модели **не ниже 10** слов в секунду.
  - **Вариант Б (запасной):** Qwen3-4B Q4 + Whisper large-v3-turbo на той же карте (~4,5 ГБ). Бери, если вариант А не влез, упал или замедлился.
  - **Вариант В:** Qwen3-8B на карте + Whisper `small` на процессоре. Бери, только если 4B отвечает заметно хуже на проверке `tools/eval_assistant.py`, а распознавание на процессоре укладывается в 2 секунды на 5 секунд речи.
  Запиши в отчёт, какой вариант выбран, и фактические цифры видеопамяти и скорости для тех, что пробовал.
- Занятая видеопамять: Windows — «Диспетчер задач» → «Графический процессор» → «Выделенная память» (или счётчики `Get-Counter '\GPU Adapter Memory(*)\Dedicated Usage'`); Linux — `cat /sys/class/drm/card*/device/mem_info_vram_used`.

## Правила

1. **Источники только официальные:**
   - llama.cpp — `https://github.com/ggml-org/llama.cpp` (релизы или сборка из исходников);
   - whisper.cpp — `https://github.com/ggml-org/whisper.cpp`, модели — `https://huggingface.co/ggerganov/whisper.cpp`;
   - Qwen3 — `https://huggingface.co/Qwen/Qwen3-8B-GGUF` (и `Qwen/Qwen3-4B-GGUF`, `Qwen/Qwen3-14B-GGUF` для запасных вариантов);
   - синтез голоса — модель Silero `https://models.silero.ai/models/tts/ru/v4_ru.pt`, PyTorch для процессора — с `https://download.pytorch.org/whl/cpu` или PyPI; запасной Piper — `pip install piper-tts`, голоса — `https://huggingface.co/rhasspy/piper-voices`;
   - драйверы — из репозиториев ОС или с amd.com.
   Если для файла опубликована контрольная сумма — сверь.
2. **Не делай без подтверждения человека:** переустановку или обновление ОС и драйверов с перезагрузкой, удаление чужих файлов и программ, изменение настроек безопасности, брандмауэра и учётных записей, открытие портов наружу из локальной сети.
3. **Пароли и ключи не вводишь сам.** Нужен вход в GitHub (`gh auth login`), пароль sudo или ключ облачной модели — попроси человека ввести его.
4. **Без обходов:** никаких VPN и прокси для обхода региональных ограничений. Никакого клонирования голосов реальных людей — только стандартные голоса Silero или Piper.
5. Все службы слушают только `127.0.0.1`, кроме нашего сервера (он в локальную сеть — через `--lan`).
6. Если шаг не получается — не подменяй решение молча. Запиши, что пробовал, и иди по запасному варианту из раздела «Если не работает».

## Шаги

### 0. Разведка
- Определи ОС и версию. Рекомендуемая — **Ubuntu 24.04** (драйвер Mesa RADV уже есть). Windows 10/11 тоже подходит (драйвер AMD Adrenalin).
- Проверь, что карта видна через Vulkan: `vulkaninfo --summary` (Ubuntu: пакет `vulkan-tools`; Windows: из Vulkan SDK или по выводу `llama-server --list-devices`). Должно быть одно устройство RX 580 / Polaris (встроенная графика процессора, если есть, не в счёт).
- **Проверь процессор на AVX2** (Linux: `lscpu | grep -o avx2`; Windows: модель процессора через `Get-CimInstance Win32_Processor`). Если AVX2 нет — готовые сборки llama.cpp и whisper.cpp могут падать с «illegal instruction»: собирай обе из исходников на этом ПК. Если не запустится PyTorch — сразу переходи на Piper для синтеза голоса.
- Оперативной памяти 16 ГБ: перед запуском закрой лишние программы, посмотри, сколько свободно.
- Свободное место на диске — нужно не меньше **20 ГБ**.
- Сразу запусти в фоне загрузку модели голоса Silero (шаг 4): её сервер бывает очень медленным (замечали ~40 КБ/с), 40 МБ могут качаться минут двадцать.
- Поставь, если нет: `git`, `python3` 3.10+, `pip`, `ffmpeg`, `cmake` и компилятор (для сборки), `curl`.

### 1. Репозиторий
```bash
git clone https://github.com/ilyarlgkh7465-ctrl/space-hackathon.git ~/space-hackathon
```
Если репозиторий закрыт — попроси человека выполнить `gh auth login`. Рабочая папка для моделей и программ: `~/fp-ai/` (Windows: `C:\fp-ai\`).

### 2. Языковая модель — llama.cpp (Vulkan), карта 0
- Возьми готовую сборку Vulkan из релизов (архив с `vulkan` в имени под твою ОС). Нет подходящей — собери: `cmake -B build -DGGML_VULKAN=ON && cmake --build build --config Release -j`.
- Скачай `Qwen3-8B-Q4_K_M.gguf` (~5 ГБ) в `~/fp-ai/models/`.
- Запуск:
```bash
llama-server -m ~/fp-ai/models/Qwen3-8B-Q4_K_M.gguf --device Vulkan0 -ngl 99 -c 4096 \
  --host 127.0.0.1 --port 8080 --jinja --reasoning-budget 0
```
- Контекст 4096, а не 8192: на одной карте бережём видеопамять под распознавание речи.
- Сразу скачай и запасную модель `Qwen3-4B-Q4_K_M.gguf` (~2,6 ГБ) — чтобы не ждать загрузки, если придётся перейти на вариант Б.
- Флаги сверь с `llama-server --help` своей версии. `--reasoning-budget 0` отключает «размышления» Qwen3 — если флага нет, найди аналог в `--help`.
- В логе запуска должно быть видно, что слои ушли на Vulkan0 («offloaded 37/37 layers to GPU» или похожее). Если всё на процессоре — проблема с Vulkan, разберись до перехода дальше.

### 3. Распознавание речи — whisper.cpp (Vulkan), та же карта
- Собери с Vulkan: `cmake -B build -DGGML_VULKAN=1 && cmake --build build --config Release -j` (или готовая сборка, если в релизах есть Vulkan).
- Модель: `ggml-large-v3-turbo-q5_0.bin` (~550 МБ) — скриптом `models/download-ggml-model.sh large-v3-turbo-q5_0` или с Hugging Face.
- Запуск на **той же** карте, что и языковая модель, и строго **после** `llama-server` (устройство выбирать не нужно). После запуска сделай по одному тестовому запросу к обеим программам и посмотри занятую видеопамять — по ней решается, остаёмся на варианте А или переходим на Б:
```bash
whisper-server -m ~/fp-ai/models/ggml-large-v3-turbo-q5_0.bin -l ru --host 127.0.0.1 --port 8090
```

### 4. Синтез голоса — Silero, процессор
Сервис синтеза уже есть в репозитории: `tools/tts_server.py`. Ставишь только его зависимости и модель.
```bash
python3 -m venv ~/fp-ai/tts
~/fp-ai/tts/bin/pip install torch numpy --index-url https://download.pytorch.org/whl/cpu   # Windows: pip install torch numpy
mkdir -p ~/fp-ai/models && curl -L -o ~/fp-ai/models/v4_ru.pt https://models.silero.ai/models/tts/ru/v4_ru.pt
~/fp-ai/tts/bin/python ~/space-hackathon/tools/tts_server.py --engine silero --model ~/fp-ai/models/v4_ru.pt --speaker aidar --port 5050
```
- Проверка: `curl http://127.0.0.1:5050/` → `{"ok": true, "engine": "silero", ...}`; `curl -X POST -d '{"text":"Добрый день! Требуют решения: 5."}' http://127.0.0.1:5050/synthesize -o test.wav` — файл звучит, цифры прочитаны словами.
- **Образцы для выбора на слух:** сделай одну и ту же фразу голосами `aidar`, `eugene`, `baya`, `xenia` в `~/fp-ai/samples/`. Голос выбирает человек; выбранный — в автозапуск (`--speaker`).
- Лицензия Silero — CC BY-NC-SA 4.0 (только некоммерческое использование): запиши в отчёт.
- **Запасной вариант — Piper**, если Silero не ставится или звучит медленнее реального времени:
```bash
python3 -m venv ~/fp-ai/piper && ~/fp-ai/piper/bin/pip install piper-tts
cd ~/fp-ai/voices && ~/fp-ai/piper/bin/python -m piper.download_voices ru_RU-denis-medium
~/fp-ai/piper/bin/python ~/space-hackathon/tools/tts_server.py --engine piper --model ~/fp-ai/voices/ru_RU-denis-medium.onnx --port 5050
```
  Piper ставь в папку с коротким путём (`~/fp-ai`): при длинном пути он не находит данные произношения (`phontab`).

### 5. Наш сервер
```bash
cd ~/space-hackathon
LOCAL_LLM_URL=http://127.0.0.1:8080/v1 LOCAL_LLM_MODEL=qwen3-8b AI_MODE=local python3 server.py --lan
```
- Порт 8800. Кода не правь — сервер ходит в модель по OpenAI-совместимому адресу.
- Голосовой чат по умолчанию ищет распознавание на `http://127.0.0.1:8090` и синтез на `http://127.0.0.1:5050`; если порты другие — передай `STT_URL` и `TTS_URL`. Проверка: `GET /api/assistant/voice/status` после входа должен вернуть `stt: true, tts: true`.

### 6. Автозапуск
- Ubuntu: четыре службы systemd (`fp-llm`, `fp-stt`, `fp-tts`, `fp-server`) с `Restart=on-failure`; сервер стартует после трёх остальных.
- Windows: скрипт `C:\fp-ai\start-ai.ps1`, который поднимает всё по порядку, и задача в Планировщике заданий при входе в систему.
- Сохрани скрипты или юнит-файлы в `~/fp-ai/` и перезагрузи ПК (спроси человека), чтобы проверить автозапуск.

## Если не работает

- **Vulkan не видит карту или модель считается процессором** → обнови Mesa (Ubuntu) или драйвер AMD (Windows) — с подтверждением человека; проверь `vulkaninfo`.
- **Скорость модели ниже 10 слов в секунду или не хватает видеопамяти** → вариант Б: `Qwen3-4B-Q4_K_M.gguf` на Vulkan0; запиши обе скорости в отчёт.
- **Qwen3-14B не ставим** — она рассчитана на две карты, у нас одна.
- **whisper.cpp не собирается с Vulkan** → собери без Vulkan (процессор) с моделью `ggml-small-q5_1.bin` или `large-v3-turbo-q5_0`, замерь, за сколько распознаётся 5 секунд речи (норма — меньше 2 секунд).
- **Silero не ставится, модель не скачивается или синтез медленнее реального времени** → Piper через тот же `tools/tts_server.py --engine piper` (шаг 4).
- **Не хватает места или памяти** → удали только то, что сам скачал в `~/fp-ai/`.
