# Развёртывание ИИ на демо-ПК

Железо: 2 × AMD RX 580 8 ГБ, 32 ГБ оперативной памяти. Всё работает локально, наружу ничего не уходит. Облачный режим (DeepSeek или Qwen по API) — по желанию, только ключ.

## Главное про RX 580

- **ROCm эти карты не поддерживает** (архитектура Polaris, gfx803). Поэтому обычная Ollama на них считает процессором, а PyTorch, faster-whisper и прочее «под CUDA» видеокарту не увидят.
- Рабочий путь — **Vulkan**: `llama.cpp` и `whisper.cpp` собраны под Vulkan и видят RX 580.
- Распределение: **карта 0 — языковая модель**, **карта 1 — распознавание речи**. Синтез голоса — на процессоре.
- Скорость на RX 580 мы не мерили. Ориентир: Qwen3-8B — 15–25 слов в секунду, этого хватает для голосового чата. Первым делом после установки — замерить (раздел «Проверка»).

## Шаги и параметры

### 1. Языковая модель — llama.cpp (Vulkan)

Скачать готовую сборку Vulkan со страницы релизов `ggml-org/llama.cpp` (для Windows и Ubuntu есть архивы с `vulkan` в названии) или собрать: `cmake -B build -DGGML_VULKAN=ON && cmake --build build -j`.

Модель: `Qwen3-8B-Q4_K_M.gguf` с Hugging Face (официальный репозиторий `Qwen/Qwen3-8B-GGUF`).

```bash
llama-server -m Qwen3-8B-Q4_K_M.gguf --device Vulkan0 -ngl 99 -c 8192 \
  --host 127.0.0.1 --port 8080 --jinja --reasoning-budget 0
```

- `--device Vulkan0` — только первая карта; `-ngl 99` — вся модель на видеокарте.
- `-c 8192` — контекст; хватает на вопрос + найденные пункты документов.
- `--reasoning-budget 0` — без «размышлений», иначе голосовой ответ задерживается в разы.
- Список карт: `llama-server --list-devices`.

**Запасной вариант поумнее:** `Qwen3-14B-Q4_K_M.gguf` (~9 ГБ) на обе карты: `--device Vulkan0,Vulkan1 --split-mode layer --tensor-split 1,1`. Тогда распознавание речи уходит на процессор. Медленнее — проверить, хватает ли скорости.

### 2. Распознавание речи — whisper.cpp (Vulkan)

Собрать с `-DGGML_VULKAN=1` (или взять готовую сборку), модель скачать скриптом `models/download-ggml-model.sh large-v3-turbo-q5_0`.

```bash
whisper-server -m models/ggml-large-v3-turbo-q5_0.bin -l ru --host 127.0.0.1 --port 8090
```

- Чтобы занять **вторую** карту — выбрать устройство (флаг `--device` или переменная `GGML_VK_VISIBLE_DEVICES=1`, смотреть `whisper-server --help` в вашей сборке).
- Звук: 16 кГц, моно; наш сервер сам переводит запись браузера через **ffmpeg** — ffmpeg тоже поставить.
- Подходит и для живой записи встречи (длинный звук режется по паузам).

### 3. Синтез голоса — Piper

```bash
python3 -m pip install piper-tts
python3 -m piper.download_voices ru_RU-denis-medium ru_RU-irina-medium
python3 -m piper.http_server -m ru_RU-denis-medium --port 5000
```

- Параметры: `length_scale` 1.0 (робот — 0.95), `noise_scale` 0.667, `noise_w` 0.8, пауза между предложениями 0.2 с. Звук 22 050 Гц.
- Робот и котик — эффекты в браузере поверх стандартных голосов (металлический призвук; котик выше на 3–5 полутонов). Чужие голоса не клонируем.
- Лицензии: движок Piper — GPL-3.0 (работает отдельной программой, наш код не затрагивает); лицензию каждого голоса проверить в его `MODEL_CARD` и вписать в `docs/Лицензии.md`.

### 4. Наш сервер

```bash
LOCAL_LLM_URL=http://127.0.0.1:8080/v1 LOCAL_LLM_MODEL=qwen3-8b AI_MODE=local ./start.command --lan
```

- Сервер ходит в модель по OpenAI-совместимому адресу, поэтому llama.cpp подключается без правок кода.
- Облако по желанию: `LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL` (по умолчанию DeepSeek). Текст уходит только после маскирования.
- Адреса распознавания и синтеза голоса (`STT_URL=http://127.0.0.1:8090`, `TTS_URL=http://127.0.0.1:5000`) Лёша добавляет в сервер вместе с голосовым чатом.
- **Микрофон с телефонов** работает только по https (кроме localhost) — нужен https для стенда.

## Питание и железо

- Блок питания от **650–750 Вт**: каждая RX 580 берёт до ~185 Вт, у каждой свой разъём 8-pin.
- Оперативная память: две или четыре планки (двухканальный режим), не одна.
- Если карты ещё не куплены: одна **RTX 3060 12 ГБ** проще и, скорее всего, быстрее двух RX 580 — работают Ollama, faster-whisper и PyTorch «из коробки».

## Сколько памяти займёт

| Что | Видеопамять | Оперативная память |
|---|---|---|
| Qwen3-8B (карта 0) | ~6 из 8 ГБ | ~1 ГБ |
| Whisper turbo (карта 1) | ~1–2 из 8 ГБ | ~0,5 ГБ |
| Piper | — | ~0,2 ГБ |
| Система, браузер, наш сервер | — | ~6–8 ГБ |
| **Итого** | | **~8–10 из 32 ГБ — запас большой** |

## Проверка после установки

1. `curl http://127.0.0.1:8080/v1/models` — модель отвечает; в логе `llama-server` видно, что слои ушли на Vulkan0 (а не на процессор).
2. Скорость: в логе `llama-server` после ответа — `tokens per second`. Нужно **не меньше 10**.
3. `curl -F file=@test.wav http://127.0.0.1:8090/inference` — русская фраза распознаётся.
4. Piper произносит тестовую фразу за меньшее время, чем она длится.
5. `http://127.0.0.1:8800/api/health` → `"mode": "local"`; в помощнике (`/t3/`) вопрос по документам получает ответ со ссылкой.
6. Прогнать `python3 tools/eval_assistant.py` — доля найденных задач не меньше 80 %.
