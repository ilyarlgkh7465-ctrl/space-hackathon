# Демо-ролик «Фотопринт»

`fotoprint-demo-16x9.mp4` — 53 секунды, 1920×1080, 60 кадров в секунду, со звуком. Всё, что в кадре на экранах устройств, снято с настоящих
экранов системы (локальный сервер, тестовые данные): пульт, журнал ИИ-шлюза, помощник, приложение picPac.

## Что в ролике

| Время | Сцена | Что показано |
|---|---|---|
| 0–4 | Заставка | «Одна система — руководителю, команде и клиенту» |
| 4–16 | Пульт | граф «Пульс компании» → сфера «Производство» раскрывается → показатель «Заказы в срок» → разбор до причины, «Оформить решение» |
| 16–24 | Схема шлюза | запрос → ИИ-шлюз → три маршрута подсвечиваются по очереди: локальная модель (финансы, закрытый контур), Claude (сложные разборы), DeepSeek (короткие ответы) |
| 24–36 | Помощник | телефон: вопрос голосом → ответ; режим «Встреча» → отчёт с решениями и поручениями |
| 36–48 | Приложение | заставка → продукт → фото и авто-проверка слабых кадров → оформление → статус заказа меняется с производства |
| 48–53 | Финал | «Попробуйте сами», QR на страницу «Скачать» |

## Что в ролике постановочное

- **Голос.** У съёмки нет микрофона: слова вопроса и реплики встречи подставлены текстом в те же поля, куда их пишет распознавание речи.
  Ответ помощника и отчёт по встрече — настоящие ответы моделей.
- **Скорость.** Ожидание ответа модели сжато монтажом (ответ на вопрос — около 2 с, отчёт по встрече — 7–30 с в зависимости от модели).
- **Схема шлюза** — рисованная: она показывает устройство системы (финансы — только локальная модель). Настоящего экрана шлюза в ролике нет;
  на компьютере, где шла съёмка, локальная модель не запущена.
- **Логотип** перерисован вектором по картинке 128×128 (`shared/brand/fotoprint.svg`).
- **Имя и телефон в заказе** — выдуманные.

## Как пересобрать

Нужны: запущенный сервер (`python3 server.py 8820`), Google Chrome, node 18+, Python с PyAV, numpy, scipy, Pillow
(окружение скилла: `~/.cache/screen-demo-video/bin/python`).

```bash
export WORK=/путь/к/папке/для/кадров        # около 1,5 ГБ
for s in pulse gate helper app; do node capture.mjs $s; done     # съёмка сцен (≈10 минут)
python edl.py                                                    # монтажный лист → edl.json
node render.mjs --times 5,20,30,45                               # пробные кадры в $WORK/test
node render.mjs --from 0 --to 53                                 # все кадры в $WORK/out (можно в 4 потока по частям)
python music.py $WORK/mix.wav                                    # звук
python encode.py $WORK/out $WORK/mix.wav fotoprint-demo-16x9.mp4
```

- `scenes.mjs` — что делается на экране в каждой сцене; `capture.mjs` — съёмка: анимации страницы замедляются в пять раз, кадры снимаются
  с обычной скоростью, в монтаже время сжимается обратно — движение получается плавным.
- `edl.py` — время ролика → время сцены, камера, подписи; `comp.html` — оформление (чистая функция времени);
  `music.py` — музыка и звуки интерфейса; `sheet.py <сцена> t1 t2 …` — контактный лист сцены.
