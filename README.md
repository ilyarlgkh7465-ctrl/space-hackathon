# Единая система для «Фотопринт» — Space Hackathon

Одно решение на три трека ТЗ: пульт руководителя (трек 1), мобильное приложение picPac (трек 2), ИИ-помощник руководителя (трек 3). Все данные выдуманные.

## Запуск

Нужен только Python 3.9+, ничего ставить не надо.

    ./start.command            # откроет http://127.0.0.1:8800/
    ./start.command --lan      # ещё и для телефонов в той же сети

Перед показом: кнопка «Сбросить демо-данные» на главной.

## Тестовые учётные записи

Логины: `director`, `production`, `sales`, `support`, `logistics`, `finance`, `hr`, `office`, `operator`, `quality`, `analyst`, `client`.
Пароль один на всех, лежит в `data/seed/users.json`. Права проверяет сервер по токену.

## Переменные окружения

- `LLM_API_KEY` — ключ модели (DeepSeek). В репозиторий не кладётся.
- `LLM_BASE_URL`, `LLM_MODEL` — если нужна другая модель с тем же форматом запросов.
- `LOCAL_LLM_URL`, `LOCAL_LLM_MODEL` — локальная модель (Ollama) для закрытого контура.
- `TG_BOT_TOKEN`, `TG_CHAT_ID` — отправка задач в Telegram, не обязательно.

Без ключа система работает на встроенной логике.

## Какая модель отвечает

Все запросы идут через ИИ-шлюз (`llm_gateway.py`). В режиме «По задаче» (`auto`, по умолчанию) он сам выбирает модель:

| Задача | Модель | Запасной вариант |
|---|---|---|
| Финансы (маржа, прибыль, дебиторка, бухгалтерия, зарплаты) | только локальная модель | встроенные правила — в облако не уходит никогда |
| Сложный разбор (протокол встречи, краткое содержание документа) | Claude | DeepSeek |
| Короткий ответ (вопрос по показателю, голос, чат приложения) | DeepSeek | Claude |

Что ответило на самом деле, видно в пульте: «Данные и журнал» → «ИИ-шлюз» → «Последние обращения». Директор может переключить всё на одну модель.
Claude из Беларуси без VPN не отвечает (403) — тогда сложные разборы уходят в DeepSeek, и панель это показывает.

## Стенд на сайте и приложения на телефон

- Адрес стенда: `https://fotoprint.130-49-141-77.sslip.io` — главная, `/t1/` пульт, `/helper/` помощник, `/t2/` приложение picPac, `/get/` — страница «Скачать» с QR.
- Выкладка: `tools/deploy-stand.sh` (первый раз — `--setup`, вернуть демо-данные — `--reset`). Ключи моделей — только на сервере.
- Приложения ставятся на экран телефона прямо с сайта: Android — кнопка «Установить», iPhone — Safari → «Поделиться» → «На экран „Домой“».
  Нативное iOS-приложение (`ios/`) по ссылке раздать нельзя: Apple разрешает установку только через App Store или TestFlight.
- На стенде нет локальной модели и синтеза Silero (сервер без видеокарты, 2 ГБ памяти): финансовые вопросы отвечают встроенные правила,
  голос — голос самого телефона, речь распознаёт телефон. Локальная модель развёрнута и замерена на ноутбуке — `docs/Развёртывание ИИ — отчёт по ноутбуку.md`.
- Наружу сервер отдаёт только экраны (`t1 t2 t3 shared get helper`); код, `.env`, `data/`, `docs/` закрыты.

## Что где

- `server.py` — общий сервер: вход и роли, хранилище, журнал действий, запросы к модели с маскированием.
- `pult_api.py` — расчёт показателей пульта из пяти источников, решения, события. `tools/gen_data.py` — выдуманные данные (постоянное зерно).
- `t1/` — пульт руководителя. `t2/` — приложение picPac. `t3/`, `mini/` — помощник.
- `helper/` — помощник как отдельное приложение (тот же пульт, открытый сразу на помощнике). `get/` — страница «Скачать». `shared/install.js` — установка на экран телефона.
- `shared/` — общее оформление и шрифты: `glass.css` (пульт, приложение, экран участка), `ui.css` (главная и помощник).
- `docs/Трек 2 — соответствие ТЗ.md` — что из ТЗ закрыто в приложении и чем это проверено.
- `docs/Общий бриф.md` — требования, роли, безопасность, договор между частями.
- `docs/API.md`, `docs/Тестирование.md`, `docs/Лицензии.md` — заполняются по ходу.
